title: "Program v1 (referință)"
---

**Unde în aplicație:** „Program” → „Instrumente ajutătoare” → „Program v1 · referință” (`/admin/schedule/manage`).

Program v1 este pagina veche. Aplicația o păstrează pentru referință, dar avertizează că nu mai este folosită și nu funcționează complet. Pentru programare, deschide [Program v2](/app-interface/program/sejur/prezentare).
